# IT Support Ticket System

A web application for creating, managing, and tracking IT support tickets.

## Live Demo

[Try the IT Support Ticket System](https://it-support-ticket-system-theta.vercel.app/)

## Technologies Used

- React
- TypeScript
- Vite
- CSS
- Local Storage

## Features

- Create, edit, and delete support tickets
- Assign tickets to technicians
- Set ticket priorities
- Open and close tickets
- Search and filter tickets
- Sort tickets by date, priority, or status
- View ticket statistics
- Save tickets using browser localStorage
- Responsive design
